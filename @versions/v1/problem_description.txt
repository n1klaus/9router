Fix two request-translation defects that make Claude-bound requests fail or lose conversation turns. First: when a client has already placed the maximum four cache_control markers a request may carry, the router currently adds its own re-anchor marker on top, producing five or more markers and a rejected request; after this fix a translated request never carries more than four cache_control markers, and when the client has not spent its budget the router still adds its own breakpoints. Second: a conversation turn whose content is a single content block object, rather than an array, is currently dropped from the translated request entirely; after this fix such a turn is kept, delivered to the upstream API as a one-element array, and any cache_control marker the client placed on it is removed. Normal turns with array content must continue to translate exactly as before.
